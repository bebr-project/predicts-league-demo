# Лига прогнозов — автономная демоверсия

Портфолио-версия веб-приложения для небольшой футбольной лиги. Участники выбирают исход матча, двойной шанс, «обе забьют» или тотал, ставят игровые очки и сравнивают результаты в рейтинге.

**Это демонстрация, а не действующая лига.** Все клубы, матчи, результаты, участники и коэффициенты в этой папке вымышлены. Настоящие деньги не используются.

## Что можно попробовать

- Открыть «Матчи», выбрать дату и сделать прогноз на предстоящую игру.
- Проверить минимальную ставку: после каждого пропущенного завершённого матча она увеличивается на 70 очков; сделанный прогноз сбрасывает серию пропусков.
- Посмотреть, как ставка резервирует очки и как завершённые матчи отражаются в рейтинге.
- Написать сообщение в чат, поставить реакцию и сбросить демоданные в профиле.
- Открыть упрощённую иллюстрацию плей-офф в рейтинге.

Сохранённые ставки, сообщения и реакции остаются **только в localStorage вашего браузера**. Кнопка «Сбросить демо» восстанавливает исходное состояние. Демо не выполняет сетевых запросов и не требует ключей, базы данных, регистрации или сборки.

## Запуск

Откройте `index.html` через локальный статический сервер. Из папки `portfolio-demo` достаточно запустить:

```sh
node serve.mjs
```

Затем откройте `http://localhost:8000/`. Локальный сервер нужен для загрузки JavaScript-модулей. Зависимости устанавливать не требуется. Проверка бизнес-логики:

```sh
node --test core.test.js
```

## Что отличается от рабочего приложения

| Здесь, в демо | В полном проекте |
| --- | --- |
| Вымышленные матчи и коэффициенты в `demo.js` | Футбольные данные и коэффициенты от внешних провайдеров |
| Данные только в браузере | Cloudflare Worker и D1 для общего состояния лиги |
| Локальная проверка ставок для демонстрации механики | Проверка на сервере, не доверяющая данным клиента |
| Упрощённая иллюстрация сетки | Динамическая сетка турнира |
| Нет авторизации и уведомлений | Аккаунты и Telegram-уведомления |

Локальная проверка ставки в демо **не является защитой от подмены запроса**: здесь нет сервера и ценных данных. В рабочей версии ограничения должны применяться на сервере. Демо не претендует на показ всех экранов и интеграций полного приложения.


Перед любым размещением полного рабочего проекта отдельно проверьте историю коммитов и исключите реальные дампы БД, `.env`, `.dev.vars`, токены, журналы, документы и пользовательские данные. `.gitignore` не удаляет секреты из уже опубликованной истории.

## Стек и устройство

Демо: HTML, CSS, JavaScript ES Modules, localStorage, Node.js test runner для проверок. Без npm-зависимостей и внешних API.

Полный проект: клиентский JavaScript, Cloudflare Workers, D1, внешние источники футбольных данных и коэффициентов. Эта отдельная папка показывает пользовательский сценарий и часть правил лиги без раскрытия ключей и пользовательских данных.
